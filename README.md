# Chess Game

A complete chess game implementation with a clean, interactive interface.

## Features

- Full chess game logic with all standard rules
- Move validation and legal move generation
- Check, checkmate, and stalemate detection
- Move history tracking
- Piece highlighting and valid move indicators
- Responsive web-based interface

## How to Play

1. Open `index.html` in a web browser
2. Click a piece to select it
3. Click a highlighted square to move the piece
4. White moves first
5. Game ends when checkmate or stalemate occurs

## Files

- `index.html` - Main game interface
- `chess.js` - Core game logic
- `style.css` - Game styling
- `README.md` - This file

## Rules

- All standard chess rules are implemented
- Castling is available when conditions are met
- En passant capture is supported
- Pawns promote to Queen when reaching the opposite end
